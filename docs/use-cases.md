# Use Cases

The prototype supports two main user groups:

- organizers in the administrative area,
- participants and viewers in the public area.

## Organizer use cases

### Manage tournaments

Organizers can create, edit, search, filter and delete tournaments.  
Each tournament contains date information, location, number of rounds, status and an optional description.

### Manage participants

Organizers can create, edit, search and filter participants.  
Participant data includes name, email, birth date, country, club and rank.

### Manage registrations

Organizers can create and edit registrations for existing participants.  
A registration links one participant to one tournament and stores the selected rounds in which the participant is expected to play.

### Provide public self-registration

Organizers can open a tournament for registration by setting its status accordingly.  
Participants can then register themselves through the public form.

### Generate start lists

Organizers can view start lists per round.  
The start list only includes participants who selected the respective round.

### Export participants for MacMahon

Organizers can export the tournament registration data into a MacMahon-compatible text format.  
The export includes participant name, rank, country, club and selected rounds.

### Import pairings from MacMahon

Organizers can import pairings generated by MacMahon for a selected round.  
The imported data is validated and stored internally.

### Edit results

Organizers can enter or update results for imported pairings.  
Supported result states include black win, white win, jigo, both lose, both win and open result.

### Publish and unpublish pairings

Organizers can publish or unpublish the pairings of each round.  
Only published pairings are visible in the public area.

### Import and publish standings

Organizers can import a MacMahon wall-list file as the current tournament standing.  
After import, the standings are initially internal and must be explicitly published.

## Public user use cases

### View tournaments

Public users can view and filter available tournaments.

### View tournament details

Public users can view public tournament information such as location, dates, status, number of rounds and description.

### Register for a tournament

Participants can register for a tournament if registration is open.  
They enter personal data, rank, optional club and country information, and select the rounds in which they want to participate.

### View start list

Public users can view the start list for a selected round.

### View pairings and results

Public users can view pairings and results that have been published by the organizer.

### View standings

Public users can view the currently published tournament standings.
